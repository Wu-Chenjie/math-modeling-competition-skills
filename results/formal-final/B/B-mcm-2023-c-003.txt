# 建模报告：B-mcm-2023-c

## 1. 问题框架

目标是利用 2023 MCM Problem C 的 Wordle 历史记录，建立可校准的结果分布预测模型，并识别不同答案词对应的难度类别。对日期 \(t\)，定义结果类别 \(k\in\{1,\ldots,6,F\}\)，其中 \(F\) 表示六次未解出；令 \(p_{t,k}\) 为该类别比例，满足 \(p_{t,k}\ge0,\sum_kp_{t,k}=1\)。

建议输出：

- 每日七类别结果概率及预测区间；
- 答案词难度评分与分类；
- 严格时间外推下的预测性能；
- 对词汇特征、时间漂移和样本量变化的稳健性结论。

## 2. 数据审计

- 数据文件：`official-data.zip`，内含 `2023_MCM_Problem_C_Data.xlsx`；

## 3. 假设

1. 每行代表一个按时间排序的 Wordle 答案日。
2. 七类别比例是同一批玩家的组成数据，四舍五入误差允许存在。
3. 玩家群体、报道机制和答案选择机制可能随时间变化。
4. 预测时只能使用当日之前的信息及答案词本身可预先计算的特征。
5. 词汇特征不应使用结果列或未来日期信息。

## 4. 候选模型

每个预测任务至多保留两个独立体系：

**模型 A：动态组成回归（主模型）**

以七类别概率为响应，使用 softmax 状态空间模型：

\[
p_{t,k}=\frac{\exp(\eta_{t,k})}{\sum_j\exp(\eta_{t,j})},
\qquad
\eta_{t,k}=\alpha_k+x_t^\top\beta_k+u_{t,k},
\]

\[
u_{t,k}=\rho_k u_{t-1,k}+\epsilon_{t,k}.
\]

若存在每日玩家数 \(n_t\)，采用
\[
y_t\sim\mathrm{Multinomial}(n_t,p_t);
\]
若只有比例，则使用 Dirichlet/quasi-multinomial 似然并按有效样本量加权。\(x_t\) 包括日期趋势和答案词特征。

**模型 B：时间阻塞的梯度提升多分类模型**

将难度定义为训练集内预先登记的分位数等级，使用词长固定为五、字母频率、重复字母、元音数、位置模式等特征，输出七类别或难度等级概率；采用温度缩放/等距回归校准。特征仅来自答案词和历史窗口。

## 5. 基线

- 全历史平均组成分布（Dirichlet 平滑）；
- 时间持久性基线：\(\hat p_t=p_{t-1}\)；
- 难度分类的多数类基线；
- 无词特征的时间模型，用于检验词特征增益。

## 6. 数学与实验规格

预处理步骤：

1. 解析表头并建立字段字典；
2. 按日期排序，检查重复日期、缺失和比例和；
3. 将百分比转为比例；若比例和偏离 1，记录偏差并进行闭合或保留为质量特征；
4. 构造词特征，所有频率统计仅在训练折内计算；
5. 对极端稀有类别使用平滑，不删除真实失败记录。

实验采用滚动时间外推：

- 初始训练窗：前 60%；
- 验证窗：随后 20%，用于调参和阈值登记；
- 最终测试窗：最后 20%，只使用一次；
- 另做 expanding-window rolling-origin 评估。

伪代码：

```text
audit -> sort by date -> construct leakage-safe features
fit persistence and mean baselines
fit dynamic compositional model
fit calibrated boosted classifier
evaluate each forecast origin
freeze parameters -> final holdout report
```

所有执行结果目前均为待运行。

## 7. 验证指标

组成预测：多项式对数损失、Brier 分数、逐类别 MAE、总变差距离、预测区间覆盖率。  
分类预测：macro-F1、balanced accuracy、log loss、可靠性曲线和校准误差。  
报告模型相对基线的差值及 bootstrap 置信区间，而非只报告单一最高分。

## 8. 敏感性与稳健性

改变：

- 训练窗口长度和时间趋势阶数；
- Dirichlet 浓度/过度离散参数；
- 词特征集合及其消融组合；
- 难度分位点定义；
- 是否按玩家数加权；
- 缺失处理与比例闭合方式。

若模型排名、难度排序或关键系数在合理设定下改变，应降低结论强度。

## 9. 反证与伪检验

- 随机置换答案词，检验词特征是否产生虚假增益；
- 打乱时间顺序，确认时间模型优势消失；
- 使用未来词特征的禁止性泄漏测试；
- 以随机日期作为 placebo 预测目标；
- 比较“仅时间”“仅词特征”“时间+词特征”三种规格。

## 10. 审稿风险

主要风险是时间泄漏、词汇特征过拟合、组成数据闭合约束被忽略、百分比四舍五入、玩家样本量变化、类别定义任意化，以及将相关性误述为答案词导致的因果效应。摘要中的表头不完整也是复现和解释风险。
