# 题目分析报告

本次预注册运行针对 CUMCM 2022 C 题四个子问题：风化与类型/纹饰/颜色关系及风化前成分预测；高钾与铅钡分类和亚类划分；未知样品鉴别；分类型成分关联比较。完整结构化报告见 `modeling_report.md`，机器结果见 `results/metrics.json`。

数据审计仅使用确定性 case-summary JSON 的 `rows_data`：表单1 58 行、表单2 69 行、表单3 8 行。按 85%--105% 总和规则，表单2 有效 67 行、无效 2 行。空白成分按未检测记为 0；重复采样点按文物编号分组，分类验证采用按文物留一法避免泄漏。

模型合同：成分数据先作 1e-4 零替换和 CLR 变换；分类采用 CLR 最近质心，亚类采用类内确定性二均值；Q1 采用列联表 Cramér's V 与分组均值；Q4 采用类内 CLR Pearson 相关及 Fisher-z 差异。所有数值均由 `run_model.py` 实际运行产生。因输入是审计摘要而非完整二进制附件，结论仅对所给行有效，不作因果解释。
